## Task

Add translation keys for the `{{feature}}` feature and show how to use them in components.

## Translation File Location

`src/locales/en/translation.json`

## Key Naming Convention

```
{feature}.{context}.{key}

Examples:
issues.title              → "Issues"
issues.list.empty         → "No issues found"
issues.list.loading       → "Loading issues..."
issues.detail.title       → "Issue Details"
issues.actions.create     → "Create Issue"
issues.actions.edit       → "Edit"
issues.actions.delete     → "Delete"
issues.states.reported    → "Reported"
issues.states.confirmed   → "Confirmed"
issues.types.pothole      → "Pothole"
issues.validation.required → "This field is required"
common.buttons.save       → "Save"
common.buttons.cancel     → "Cancel"
errors.generic            → "Something went wrong"
```

## Usage in Components

### Basic Usage
```typescript
import { useTranslation } from 'react-i18next';

const MyComponent: FC = () => {
  const { t } = useTranslation();

  return (
    <Typography>{t('{{feature}}.title')}</Typography>
  );
};
```

### With Variables
```typescript
// Translation: "Welcome, {{name}}!"
<Typography>{t('welcome', { name: user.name })}</Typography>

// Translation: "{{count}} items"
<Typography>{t('items', { count: items.length })}</Typography>
```

### Pluralization
```json
{
  "items": "{{count}} item",
  "items_plural": "{{count}} items"
}
```

```typescript
t('items', { count: 1 })  // "1 item"
t('items', { count: 5 })  // "5 items"
```

### In Forms (with Zod)
```typescript
const schema = z.object({
  email: z.string().email(t('validation.email.invalid')),
  name: z.string().min(1, t('validation.required')),
});
```

### With MUI Components
```typescript
<TextField
  label={t('{{feature}}.fields.name')}
  error={!!errors.name}
  helperText={errors.name?.message}
/>

<Button>{t('common.buttons.save')}</Button>

<Typography color="error">{t('errors.generic')}</Typography>
```

### Dynamic Keys
```typescript
// For states/types
const stateLabel = t(`issues.states.${issue.state}`);
const typeLabel = t(`issues.types.${issue.type}`);
```

## Adding New Keys

1. Open `src/locales/en/translation.json`
2. Add keys under the feature namespace:

```json
{
  "{{feature}}": {
    // Add new keys here
    "{{key1}}": "{{value1}}",
    "{{key2}}": "{{value2}}"
  }
}
```

3. For nested keys:

```json
{
  "{{feature}}": {
    "{{context}}": {
      "{{key}}": "{{value}}"
    }
  }
}
```
